## 3. Frozen v0.1.1 behavior

Source recovery must preserve the already accepted single-capability boundary:

- every User owns one non-null, globally unique mutable Display Name;
- normalization uses NFKC plus casefold;
- defaults are `user_` plus ten cryptographically random lowercase ASCII letters
  or digits;
- the first manual rename is immediate and later manual renames have a seven-day
  cooldown;
- former normalized names are protected for 15 days without retaining a User
  relationship after Account Closure;
- Display Name is not Login Identity, a credential, authorization/ownership key,
  account-linking signal, audit identity, Administrator identity, or Hermes field;
- `PATCH /api/me/profile` is the only self-service mutation;
- `GET /api/me` must expose an explicit `CurrentUserResponse` OpenAPI schema;
- no avatar, biography, public profile, username login, Session-management,
  Linux.do, payment, or unrelated optimization is added to this recovery slice.
